# 🏐 The Spike Cross Index

Unofficial fan-made character database for **The Spike Cross**.

This website allows users to explore character information, including:

* Character profiles
* Position and role
* Manual stat allocation
* Breakthrough bonuses
* Recommended / Max stats
* Character skills
* Synergies
* Overall performance information

---

## 📸 Preview

The website displays a character database with filtering and search functionality.

Users can filter characters by:

* ALL
* WS — Wing Spiker
* MB — Middle Blocker
* SE — Setter

Users can also search characters by name.

## 🚀 How to Run

No installation is required.

Simply open:

```text
index.html
```

in your browser.

You can also deploy the project using GitHub Pages.

---

## 🌐 Deploy to GitHub Pages

1. Upload this project to a GitHub repository.
2. Open the repository settings.
3. Go to:

```text
Settings → Pages
```

4. Select:

```text
Deploy from a branch
```

5. Choose:

```text
Branch: main
Folder: / (root)
```

6. Save.

GitHub will generate a website URL for your project.
